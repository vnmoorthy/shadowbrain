# Code of Conduct

This project follows the Contributor Covenant 2.1.

## Our standards

- Be welcoming. New contributors and skeptics are equally valuable.
- Disagree about the technical, not the personal.
- Keep code reviews about code. Keep design reviews about design.
- Surface security concerns through the channel in `docs/SECURITY.md`, not public issues.

## Reporting

For conduct issues: email moorthy@shadowbrain.dev (or the maintainer listed in `package.json`).

## Enforcement

The maintainers reserve the right to remove comments, commits, code, issues, or contributors for behavior that violates this code.

The full Contributor Covenant 2.1 text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
